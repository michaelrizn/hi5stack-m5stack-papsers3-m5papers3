# Документация hi5stack

## Обзор

hi5stack — это PlatformIO Arduino-прошивка для устройств класса M5Stack/M5Paper на ESP32. Проект даёт модульный сенсорный интерфейс для SD-файлов, просмотра TXT/BMP, Wi-Fi, встроенных приложений, игр и SD Gateway — веб-интерфейса для файлов на SD-карте.

Проект ранний и экспериментальный. Успешная сборка не означает, что все сценарии уже проверены на устройстве, особенно выключение и энергопотребление PaperS3.

## Сборка и разработка

- Сборка: `pio run`
- Загрузка на устройство: `pio run -t upload`
- Serial monitor: `pio device monitor -b 115200`

Активная среда PlatformIO — `PaperS3`. Версии библиотек закреплены в `platformio.ini`: M5Unified, M5GFX, ArduinoJson, AnimatedGIF и epdiy по конкретному commit.

## Архитектура

Основной код находится в `src/`.

- `main.cpp`: `setup()`, `loop()`, маршрутизация касаний, обновление анимаций, цикл SD Gateway.
- `ui.cpp` / `ui.h`: глобальное состояние экранов, наборы footer-кнопок, буфер строк, рендеринг, навигация и перенос текста.
- `footer.cpp` / `button.cpp`: footer и базовая кнопка.
- `sdcard.cpp`: инициализация SD, статус карты, вывод списка файлов.
- `settings.cpp`: настройки в JSON на SD-карте, включая Wi-Fi и последние данные подключения.
- `battery.cpp`: напряжение и процент заряда.
- `power_shutdown.cpp`: общий сценарий выключения для Off и Freeze.
- `sd_gateway.cpp`: файловый веб-интерфейс на базе `WebServer`.

Группы функций:

- `screens/`: главный экран, файлы, просмотр TXT/BMP, Wi-Fi, приложения, игры, SD Gateway, очистка, выключение.
- `apps/`: калькулятор, reader, geometry test, swipe test, test2, text language test.
- `games/`: сапёр, судоку, тестовая игра.
- `buttons/`: действия footer-кнопок Home, Files, Refresh, Rotate, Freeze, Off.
- `keyboards/`: английская и цифровая экранные клавиатуры.
- `network/`: Wi-Fi manager.
- `services/`: резерв для будущих сервисов.

## Основные сценарии

Главный экран показывает батарею, SD-карту, Wi-Fi, SD Gateway, а также переходы в Apps и Games. Касания обрабатываются в `main.cpp` и передаются в нужный экран по `currentScreen`.

Файловый менеджер читает SD-карту, разделяет папки и файлы, сортирует группы, показывает страницы и открывает `.txt` в текстовом просмотрщике, а `.bmp` — в просмотрщике изображений.

Reader использует папку `/books/`, читает `.txt`, разбивает текст на страницы и сохраняет позицию чтения в `/books/reader_state.json`.

Wi-Fi экран сканирует сети асинхронно через `WiFiManager`, открывает ввод пароля с английской клавиатурой и может подключаться по сохранённым данным.

SD Gateway запускается только при подключённом Wi-Fi. В браузере на порту `8080` доступны список файлов, загрузка, удаление, массовое удаление и редактирование безопасных `.txt`/`.json` файлов.

## Приложения и игры

Приложения:

- Calculator: базовые арифметические операции и AC.
- Reader: список книг, пагинация, сохранение позиции.
- Geometry test: анимированные случайные фигуры.
- Swipe test: отслеживание касаний и свайпов.
- Test2: минимальное тестовое приложение.
- Text language test: проверка английского, русского, японского и китайского текста.

Игры:

- Minesweeper: поле 10x15 и 25 мин.
- Sudoku: судоку 6x6 с цифровой клавиатурой и проверкой.
- Test game: простая проверка отрисовки и касаний.

## UI/UX заметки

Интерфейс основан на строках: `EPD_WIDTH = 540`, `EPD_HEIGHT = 960`, высота строки 60 px, footer рисуется внизу. Многие экраны зависят от этих координат. Изменения вёрстки нужно делать осторожно и проверять на устройстве.

Для видимых изменений желательно проверить главный экран, файловый менеджер, TXT/BMP просмотрщики, reader, Wi-Fi, калькулятор, сапёр, судоку и экран SD Gateway.

## SD-карта и файлы

SD-карта инициализируется в `setup()` через SPI-пины из `sdcard.h`. Настройки лежат в `/settings.json`. Книги reader — в `/books/`. Файловые операции должны работать только с безопасными путями от корня SD и отклонять `..`.

Поддерживаемые пользовательские типы:

- `.txt`: текстовый просмотрщик и reader.
- `.bmp`: просмотрщик изображений.
- `.json`: редактирование через SD Gateway для безопасных файлов.

## Отладка

Флаги отладки находятся в `src/debug_config.h`. Для обычной сборки подробный debug лучше держать выключенным и включать отдельные флаги при проверке касаний, клавиатур, файлов, Wi-Fi или SD Gateway.

## Известные риски и улучшения

- Выключение зависит от платы и PMIC, нужна проверка на устройстве.
- SD Gateway не имеет авторизации и подходит только для доверенной локальной сети.
- UI использует фиксированные координаты и требует аппаратной проверки после изменений.
- Большие файлы могут фрагментировать heap на ESP32, лимиты файлов должны оставаться консервативными.
