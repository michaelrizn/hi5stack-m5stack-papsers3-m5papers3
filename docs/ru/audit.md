# Заметки аудита

## Проверенная база

- `pio run` успешно проходит для окружения `PaperS3`.
- До рефакторинга сборка занимала примерно 20.7% RAM и 20.3% Flash.

## Проверенные зоны

- Операции SD Gateway и генерация HTML/JSON.
- Выделение памяти и BMP parsing в просмотрщике изображений.
- Загрузка файлов, пагинация и состояние reader.
- Сортировка и пагинация файлового менеджера.
- Значения debug-макросов по умолчанию.
- Уже существующие изменения выключения в `power_shutdown.*`, `off.cpp`, `freeze.cpp`, `off_screen.cpp`.

## Важные риски

- SD Gateway не имеет авторизации. Использовать только в доверенной локальной Wi-Fi сети.
- UI зависит от фиксированных координат. Видимые изменения нужно проверять на устройстве.
- Большие файлы и полные image buffers могут давить на heap ESP32.
- Выключение требует аппаратной проверки, потому что зависит от платы и PMIC.

## Ручные проверки

- Главный экран и статусные строки.
- Навигация и пагинация файлового менеджера.
- TXT viewer и BMP viewer.
- Reader: список книг, страницы, сохранение позиции.
- Wi-Fi: сканирование, ввод пароля, повторное подключение.
- SD Gateway: list/upload/delete/edit.
- Запуск calculator, minesweeper, sudoku и test game.
