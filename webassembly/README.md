# M5Stack Games WebAssembly Emulator

Этот эмулятор позволяет запускать игры M5Stack в браузере без изменения исходного кода игр.

## Возможности

- 🎮 Запуск игр M5Stack в браузере
- 🖱️ Эмуляция касаний через клики мыши
- 📱 Точное воспроизведение экрана M5Stack (540x960)
- 🔄 Автоматическая компиляция игр в WebAssembly
- 🎯 Поддержка всех основных функций M5.Display API

## Требования

- Emscripten SDK
- Make
- Современный веб-браузер с поддержкой WebAssembly

## Установка Emscripten

```bash
# Клонируем Emscripten
git clone https://github.com/emscripten-core/emsdk.git
cd emsdk

# Устанавливаем последнюю версию
./emsdk install latest
./emsdk activate latest

# Добавляем в PATH
source ./emsdk_env.sh
```

## Сборка игр

```bash
# Переходим в папку webassembly
cd webassembly

# Собираем все игры
make all

# Или собираем конкретную игру
make minesweeper
make sudoku
make test

# Очистка
make clean
```

## Использование

### Автоматический запуск (рекомендуется)

1. Убедитесь, что у вас установлен Emscripten SDK
2. Запустите эмулятор одной командой:
   ```bash
   ./start_emulator.sh
   ```
   Этот скрипт автоматически:
   - Проверит зависимости
   - Запустит сервер компиляции на порту 8001
   - Запустит веб-сервер на порту 8000
   - Откроет браузер
   - Автоматически скомпилирует игры при необходимости

### Ручной запуск

1. Убедитесь, что у вас установлен Emscripten SDK
2. Скомпилируйте игры:
   ```bash
   make all
   ```
3. Запустите локальный веб-сервер:
   ```bash
   python3 -m http.server 8000
   ```
4. Откройте браузер и перейдите на `http://localhost:8000`

### Автоматическая компиляция

Эмулятор автоматически проверяет и компилирует игры при запуске:
- Проверяет наличие исходных файлов в `../src/games/`
- Сравнивает даты изменения исходников и скомпилированных файлов
- Автоматически перекомпилирует устаревшие игры
- Показывает статус компиляции на главной странице

## Запуск

1. Соберите игры командой `make all`
2. Запустите локальный веб-сервер в папке `webassembly`:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (если установлен http-server)
   npx http-server
   ```
3. Откройте браузер и перейдите на `http://localhost:8000`
4. Выберите игру из списка

## Поддерживаемые игры

- **Minesweeper** - Классический сапёр
- **Sudoku** - Судоку 6x6
- **Test** - Тестовая игра

## Поддерживаемые функции M5.Display API

- `fillRect()` - Заливка прямоугольника
- `setCursor()` - Установка позиции курсора
- `setTextColor()` - Установка цвета текста
- `setTextSize()` - Установка размера текста
- `print()` - Вывод текста
- `drawLine()` - Рисование линии
- `drawRect()` - Рисование прямоугольника
- `drawCircle()` - Рисование окружности
- `fillCircle()` - Заливка окружности
- `textWidth()` - Получение ширины текста
- `clear()` - Очистка экрана

## Эмуляция касаний

- **Клик мыши** - эмулирует касание (touchType = 1)
- **Нажатие мыши** - эмулирует начало касания (touchType = 0)

## Добавление новых игр

1. Создайте игру в папке `../src/games/your_game/`
2. Убедитесь, что игра использует стандартный интерфейс:
   - `void initGame()`
   - `void drawGameScreen()`
   - `void handleTouch(int touchType, int x, int y)`
   - `void resetGame()`
3. Добавьте название игры в переменную `GAMES` в Makefile
4. Запустите `make your_game`

## Отладка

- Откройте Developer Tools в браузере для просмотра ошибок
- Проверьте консоль на наличие ошибок WebAssembly
- Убедитесь, что все файлы загружены корректно

## Ограничения

- Не поддерживаются функции, специфичные для аппаратного обеспечения M5Stack
- Некоторые продвинутые функции M5Unified могут не работать
- Производительность может отличаться от реального устройства

## Устранение неполадок

### Ошибка компиляции
- Убедитесь, что Emscripten установлен и активирован
- Проверьте, что все зависимости доступны

### Игра не загружается
- Проверьте консоль браузера на ошибки
- Убедитесь, что файлы .js и .wasm созданы
- Попробуйте пересобрать игру

### Касания не работают
- Убедитесь, что игра правильно обрабатывает события касаний
- Проверьте координаты в консоли браузера
